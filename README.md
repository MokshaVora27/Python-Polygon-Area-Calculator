# Python-Polygon-Area-Calculator

This project was developed as part of the freeCodeCamp Python curriculum.

## Project Description

The Shape Calculator allows users to create rectangle and square objects, calculate area, perimeter, and diagonal length, generate pictures using asterisks, and determine how many shapes can fit inside a rectangle.

## Features

- Create rectangle and square objects
- Calculate area
- Calculate perimeter
- Calculate diagonal length
- Generate rectangle pictures using asterisks
- Calculate the number of shapes that fit inside a rectangle
- Change width, height, and side dimensions
- Display shape information

## Technologies Used

- Python
- Object-Oriented Programming
- Classes and Objects
- Inheritance
- Methods and Constructors
